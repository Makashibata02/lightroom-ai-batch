# Lightroom AI Batch v1.1.0

## 中文

新增原生“AI 批处理 — 工作台…”：动物、人物、街景、风景和食物分别保存组合。

菜单只保留工作台入口。原有去杂色、完整处理、查询、取消等快捷菜单合并到工作台；处理中重新打开工作台可以刷新状态或取消当前任务，关闭窗口不取消任务。

- 保留基础去杂色、独立 Auto Tone、主体与 Landscape；可增加人像整体/皮肤/衣服/眼睛/牙齿/头发和天空预设。
- 风格预设支持搜索、收藏，首次收藏 CN13；使用原始强度，风格最后执行。
- 已处理照片可以追加模块；逐预设记录 APPLIED/COMPLETE，取消后补计算与清理，不重复提交已应用模块。
- 更换主体或 Landscape 类别会执行变化；风格 A → B → A 会重新应用 A。实时待更新的 AI 设置不会被整体跳过。
- 原有三个 batch tools 保持兼容，启动增加可选 recipe，状态增加方案和逐模块结果。
- 保留 v1.0.1 的调用隔离、迟到返回释放、取消和空蒙版恢复修复；幂等版本保留 1.0.0。
- 中英文 README、架构和包内安装说明同步更新。原配置、已处理记录和用户组合保留。

本地检查：235 项 Lua、208 项 TypeScript 测试通过，类型检查与 lint 通过。

Windows 11 + Lightroom Classic 15.5.1 实测：9/9 张 RAW 完成，失败和警告均为 0，用时 23 分 51 秒；36 个额外模块完成，保留 29 个独立 Landscape 蒙版。九张最终均为 AI 去杂色开启、50、无需更新。同方案重跑九张全部跳过，没有新的 SDK 操作。CN13 每张 35 项可读取参数与原预设一致。单张追加人像模块的取消、补完和空蒙版清理通过，无需重启 Lightroom。

一张人像的 AI 蒙版更新用时 625 秒。此工具减少重复操作，计算仍由本机完成。三个中文页签已由用户确认；精简后的状态按钮及组合保存有模拟验证，尚未再次逐项手动检查；逐像素外观对照及所有预设/场景未完全覆盖，详见[验证记录](https://github.com/Makashibata02/lightroom-ai-batch/blob/v1.1.0/docs/VALIDATION.md)。云端 AI 看图调色留在后续路线图。

升级前备份安装目录内的 `config/pipeline.json`；保留其中 UUID 和自定义设置。`workbench.json` 和处理记录位于运行状态目录，升级不覆盖。安装后重启 Lightroom 以刷新旧菜单缓存。

## English

Adds the native **AI Batch — Workbench...**, with separate saved recipes for animals, people, street, landscape and food.

Workbench is the only menu entry. Denoise, full preparation, status and cancellation are accessed there. Reopen it during processing to refresh status or cancel the displayed job; closing the window leaves the job running.

- Retains base Denoise, independent Auto Tone, Subject and Landscape; adds portrait overall/skin/clothes/eyes/teeth/hair and Sky presets.
- Search/favorite styles, initially favoriting CN13. Original preset strength; style runs last.
- Append modules to processed photos. Per-preset APPLIED/COMPLETE state lets reruns finish calculation/cleanup without repeating application.
- Changed Subject/Landscape choices run; style A → B → A reapplies A. Stale live AI state prevents whole-photo skip.
- Existing three batch tools remain compatible. Start accepts optional recipe; status includes recipe and per-module results.
- Includes v1.0.1 isolation, late-return release, cancellation and resumed empty-mask cleanup. Idempotency version stays 1.0.0.
- Both READMEs, architecture and packaged install guides are updated. Existing configuration, processed records and user recipes are preserved.

Local checks: 235 Lua and 208 TypeScript tests passed, with type checks and lint.

Windows 11 / Lightroom Classic 15.5.1: 9/9 RAWs completed with zero failures/warnings in 23 minutes 51 seconds. All 36 extra modules completed and 29 separate Landscape masks remained. Final AI Denoise was enabled at 50 and current on every photo. The same-recipe rerun skipped all nine without new SDK operations. Each photo's 35 readable CN13 fields matched the original preset. Incremental portrait cancellation, recovery and empty-mask cleanup passed without restarting Lightroom.

One portrait's AI mask update took 625 seconds. Processing still runs locally; the workbench reduces repeated operations. The user confirmed all three Chinese tabs; the simplified status buttons and recipe persistence have simulated checks but have not been manually rechecked. Pixel-level comparison and all presets/scenes are not fully covered; see the [validation record](https://github.com/Makashibata02/lightroom-ai-batch/blob/v1.1.0/docs/VALIDATION.en.md). Cloud visual grading remains future work.

Before upgrading, back up the installed `config/pipeline.json` and preserve its UUID/custom values. Runtime `workbench.json` and processing records survive upgrades. Restart Lightroom after installing to refresh cached menus.
