# Lightroom AI Batch v1.0.0

首个公开版本，面向 Windows 11 + Lightroom Classic 15.5.1。

## 主要功能

- 真正 Lightroom AI Denoise，可配置 Amount，按状态等待完成。
- 每张照片独立 Auto Tone。
- Adaptive Subject / Pop 的 UUID 发现和逐图 AI 重算。
- 八类独立 Landscape masks，空类别正常清理。
- 异步 Job、状态查询、协作取消、错误隔离、幂等跳过和完成集合。
- Landscape v2 不再清除 Denoise；包含实时校验和一次性修复。
- Lightroom UI 提供英文与简体中文。
- 可独立使用的菜单插件，以及不依赖 Node.js 的 Windows x64 MCP 包。

## 实测

- 31 张 RAW Denoise：31/31 完成。
- 18 张 RAW Full Prepare：18/18 完成。
- Windows 11 / Lightroom Classic 15.5.1；其他版本未列为实测支持。

## English

First public release for Windows 11 and Lightroom Classic 15.5.1.

- Genuine Lightroom AI Denoise with configurable Amount and state-based completion.
- Independent per-photo Auto Tone.
- UUID-based Adaptive Subject / Pop discovery and per-photo AI recomputation.
- Eight separate Landscape mask categories with normal absent-category cleanup.
- Asynchronous jobs, status, cooperative cancellation, error isolation, idempotency, and collections.
- Landscape v2 preserves Denoise, with live validation and one-shot repair.
- English and Simplified Chinese Lightroom UI.
- Standalone menu plug-in and a Node-free Windows x64 MCP package.

See `README.md`, `README.en.md`, and the validation documents for installation, limitations, and measured evidence.
